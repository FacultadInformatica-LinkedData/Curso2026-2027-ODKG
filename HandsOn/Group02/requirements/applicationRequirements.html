Application Requirements Specification

Project Name: Personalized Chicago Park & Art Explorer

1. Application Overview & Objectives

The Personalized Chicago Park & Art Explorer is a smart city web application designed to help Chicago residents and tourists discover public parks, outdoor facilities, and public artworks tailored to their geographic location, available time, and individual interests (e.g., sports, culture, family activities, sculpture walks).

By integrating open datasets from the Chicago Park District (Facilities and Artworks), the system generates customized spatial recommendations and time-restricted art walking itineraries.

2. Functional Requirements (FR)

ID Requirement Name Description Type
FR-01 Location & Preference Selection The system shall allow users to input their current location (GPS or manual park/neighborhood selection), available time budget (e.g., 30 to 180 minutes), and interest categories (Sculpture, Sports, Family, Walking, Culture). Core
FR-02 Park & Facility Recommendation The system shall recommend suitable Chicago Park District facilities based on proximity, user interests, and facility attributes. Core
FR-03 Personalized Art Itinerary Generator The application shall construct a time-bound walking route connecting relevant public artworks based on starting location and time budget (e.g., a 90-minute sculpture walking tour near Lincoln Park). Core
FR-04 Interactive Map Visualization The system shall display park facilities, artworks, and generated routes on an interactive map with turn-by-turn itinerary waypoints. Core
