How recommendations and routes are scored

  • Interest match. A facility scores 1 per selected interest its type serves (see below). Artworks score 1.0 for Sculpture, 0.8 for Culture and 0.4 for Walking, because the source data does not type artworks.
  • Distance. Recommendations lose 0.5 points per km. Walking time assumes {{ settings.walk_speed }} km/h and streets {{ settings.detour }}× longer than a straight line; each stop adds a visit of {{ settings.dwell.artwork }} min (artwork) or {{ settings.dwell.facility }} min (facility).
  • Route (FR-03). Greedy: from the current point, add the stop with the best value per minute (walk + visit) that still fits the budget; then shorten the path with 2-opt and use the saved time for more stops. At most one stop per facility type, so a walk is not five basketball courts.
